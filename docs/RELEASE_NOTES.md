First beta release for private multi-device testing.

- RTK command-output compression and CCE local context search.
- Observed before/after savings, native Codex usage, session isolation.
- Live localhost dashboard with one-second polling and recent session selection.
- Windows/Linux x64 installers, configuration backups, disable and uninstall.

Token counts use an approximate estimator. Savings describe observed
transformations and measured overhead, not an ON/OFF benchmark or billing.
Codex 0.154+ native hooks require first-use trust review. Simple pytest and
git status/diff/log/show commands are rewritten; compound commands remain native.
CCE's first model download/index can take time; native search remains available.
Root CLI sessions are supported; IDE/subagent attribution is outside this beta.
No Router, Batch, Token Optimizer, or credits estimates are included.
